# Streaming View Implementation

## Features
- Select camera from dropdown
- Start/stop streaming controls
- Displays camera stream in embedded player area
- Refresh camera list button

## Architecture Note
The system uses FFmpeg to generate HLS segments in the configured output directory. To view the streams properly, the system needs proper HTTP endpoints to serve these HLS segments to browsers. The current implementation includes:
- Camera selection and streaming controls
- Basic StreamController to attempt serving HLS files
- UI components ready for actual streaming

## Next Steps
To make full streaming work, a proper HTTP server endpoint is required to:
1. Serve HLS segment files generated by FFmpeg
2. Handle CORS and security requirements for browser access
3. Properly handle the dynamic nature of HLS streaming
